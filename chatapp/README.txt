I’ve developed a project inspired by WhatsApp with the following key features:

1. Online and Offline Status: Users can view real-time availability of their contacts.
2. Last Seen Control: Users can manage visibility of their "last seen" status.
3. Advanced User Search: Search for users by any part of their name for better discoverability.
4. Story Sharing and Interaction: Users can post images and stories, with options for others to reply.
5. Seamless Chat and Media Sharing: Share images and chat effortlessly in real time.
6. Profile Management: Users can edit their profiles to personalize their experience.
